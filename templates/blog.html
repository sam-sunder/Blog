Using Tailwind css with Django Web framework.

Mar 10, 2020 · 4 min read · Sam sunder ch

Learn how to use tailwind css with django a popular python web framework.

Django is an open-source web framework for building web applications in Python. It follows the model-view-controller architectural pattern and is widely used by many popular websites like Instagram, Spotify, etc.
This tutorial will help you to use tailwind css with django.

Setup a django project

Let's get started by creating a new django project. Make sure you have installed Python and Node.js. Now let's install django by running the following command in terminal.

pip install django

Now create a django project called my_project, Run the following command to create our project

django-admin startproject my_project

For HTML files create a folder called templates/, now add the created dir in settings.py file which is created in django project my_project/my_project/settings.py:

TEMPLATES = [ { ... 'DIRS': ['templates'], ... }, ]

Create a folder static for css, js files and a line in my_project/my_project/settings.py:

STATIC_URL = '/static/' STATICFILES_DIRS = [Path.joinpath(BASE_DIR, 'static')]
Setting up tailwind css

Create a folder npmMods and install tailwindcss by running the following commands:

npm install -D tailwindcss npx tailwindcss init

Your directory structure should look like this:

my_folder/ ├─ my_project/ │ └─ my_project/ │ ├── __init__.py │ ├── asgi.py │ ├── settings.py │ ├── urls.py │ └── wsgi.py ├─ templates ├─ static └─ npmMods/ ├─ node_modules └─ tailwind.config.js

Now we need to add our html file's location in content variable in tailwind.config.js

/** @type {import('tailwindcss').Config} */ module.exports = { content: ['../my_project/templates/**/*.html'], theme: { ... }, plugins: [], }

Create a file input.css under npmMods/src directory.

npmMods/ ├── node_modules/ ├── tailwind.config.js └── src/ └── input.css

Import tailwind css directives for each of Tailwind's layers to your main CSS file.

@tailwind base; @tailwind components; @tailwind utilities;

Run the following command in npmMods directory it scans your templates and all your classes in it and generates main tailwind.css.

npx tailwindcss -i ./src/input.css -o ../my_project/static/css/tailwind.css --watch

Make sure that tailwind.css file is created in your static folder

my_project/ ├── my_project/ ├── templates ├── static/ └─ css/ └─ tailwind.css
Start using tailwind css

You can now use tailwind css inyou template by including tailwind.css static file in the head section. Let's see an example

{% verbatim %}{% load static %}{% endverbatim %} <!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8" /> <meta http-equiv="X-UA-Compatible" content="IE=edge" /> <meta name="viewport" content="width=device-width, initial-scale=1.0" /> <title>Tailwind + Django</title> <link rel="stylesheet" href="{% static 'css/tailwind.css' %}"> </head> <body> <div class="flex h-screen items-center justify-center bg-indigo-50 px-4"> <div class="max-w-sm overflow-hidden rounded-xl bg-white shadow-md duration-200 hover:scale-105 hover:shadow-xl"> <img src="https://picsum.photos/300/150" alt="plant" class="h-auto w-full" /> <div class="p-5"> <p class="text-medium mb-5 text-gray-700">Well, aren't you going up to the lake tonight, you've been planning it for two weeks.</p> <button class="w-full rounded-md bg-indigo-600 py-2 text-indigo-100 hover:bg-indigo-500 hover:shadow-md duration-75">See More</button> </div> </div> </div> </body> </html>

Output:

Well, aren't you going up to the lake tonight, you've been planning it for two weeks.
